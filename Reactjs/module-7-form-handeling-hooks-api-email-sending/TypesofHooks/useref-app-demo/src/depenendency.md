# how to stored data using useRef and ref 
## install all dependencies 

```
npm install json-server axios sweetalert2 react-router-dom --force

```

1. json-server : create a json server to stored data in json formate

2. axios :axios is a package that can be used to get | post | put | delete | update api data

3. sweetalert2 : pass a sweet messages 

4. react-router-dom : redirect one page to another page
