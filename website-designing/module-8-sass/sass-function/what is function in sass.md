what is sass function ?


A sass function basically used to block of code that can be completed any task and return a single value. 

A sass function is used to calculate and return a single value(number , color, string , list ,map etc).

mixin is return output in css 

A sass function do not return a css directly we can return in css by using @return 

syntax : 

@function function-name($rg1,$ar2)
{
    @return value
}
