what is mixin in sass   ?
A mixin is used in sass for reusables block of css there we can used mixin.
A mixin define once and include anywhere in your stylesheet 
Mixin is help you to avoid repeatation of code ,  keep code clean and write dynamic styles using parameters , conditions and logic.

syntax :

 @mixin mixin-name {
    resusables style
 }

@include mixin-name;
