what is sass ?

Sass stands for Syntactically Awesome Stylesheets.

It is a CSS preprocessor, which means it extends normal CSS with extra features that make writing and managing styles easier. Sass code is then compiled into regular CSS, which browsers can understand.

Sass helps you write cleaner, reusable, and more organized CSS.
Instead of repeating the same styles again and again, Sass lets you use things like variables, functions, and nesting and mixin.

sass file extension .scss

How to install scss ? 

step : install node js 
step : check node js version 
step : check npm version
step : install sass globally 
       npm install -g sass --save 
step : install sass local 
       npm install sass --save
            
Step: Check Installation
sass --version
Step: Compile Sass to CSS
Create a Sass file:
style.scss
Convert it to CSS:
sass style.scss style.css
Step : Watch Mode (Auto Compile)
sass --watch style.scss:style.css

Method 2: Using VS Code Extension (Easy for Beginners)
Open VS Code
Install Live Sass Compiler
Click Watch Sass
It automatically creates a .css file
